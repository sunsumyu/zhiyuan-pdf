## 决策记录
- **不强制删除 legacy wasm_api/editor.rs**：让 facade 与 legacy 并存一段时间，
  通过 #[allow(deprecated)] + 顶部注释标识，给前端迁移时间窗口。
- **Stub API 命名是冻结的**：实施时只能改实现，不能改名/改签名。
- **WASM js_name 用 camelCase**：与 TS facade 风格一致；Rust 函数名仍 snake_case。
- **Tauri command 保留 snake_case**：Tauri 框架惯例。
